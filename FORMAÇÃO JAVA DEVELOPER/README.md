# Formação Java Developer

Este espaço guarda seus estudos de Java em formato de aulas, seguindo a mesma ideia da sua formação de lógica.

## Ordem recomendada

1. `0 - AULA INTRODUTORIA - DO JS PARA JAVA/AULA.md`
2. `1 - ANATOMIA DE CLASSES/AULA.md`
3. `2 - TIPOS E VARIAVEIS/AULA.md`
4. `2 - TIPOS E VARIAVEIS/AULA EXTRA - DUVIDAS SOBRE FUNDAMENTOS.md`
5. `3 - PROGRAMACAO ORIENTADA A OBJETOS/AULA.md`
6. `4 - ROADMAP JAVA SQL SPRING/AULA.md`

## Como estudar

Leia a aula, rode os exemplos quando houver, depois faça seus próprios exercícios na mesma pasta do módulo.

## Módulos

- `0 - AULA INTRODUTORIA - DO JS PARA JAVA`: ponte entre sua lógica em JavaScript e Java.
- `1 - ANATOMIA DE CLASSES`: estrutura básica de um programa Java.
- `2 - TIPOS E VARIAVEIS`: fundamentos, tipos, entrada de dados, operadores, arrays e métodos.
- `3 - PROGRAMACAO ORIENTADA A OBJETOS`: classes, objetos, construtores, `this`, encapsulamento e métodos.
- `4 - ROADMAP JAVA SQL SPRING`: caminho para seguir depois, incluindo SQL, banco de dados e Spring Boot.
