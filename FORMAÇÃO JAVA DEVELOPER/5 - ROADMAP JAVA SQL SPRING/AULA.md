# Aula - Roadmap Java SQL Spring

Este é o caminho recomendado para chegar em Java com Spring Boot.

## Fase 1 - Base de Java

Objetivo: escrever programas simples em Java sem travar na sintaxe.

Estude:

- anatomia de classes;
- tipos e variáveis;
- operadores;
- condicionais;
- `switch`;
- loops;
- arrays;
- métodos;
- entrada de dados com `Scanner`.

Você já tem base de lógica em JavaScript, então aqui o foco é traduzir essa lógica para Java.

## Fase 2 - Programação Orientada a Objetos

Objetivo: pensar como Java organiza sistemas.

Estude:

- classe;
- objeto;
- atributo;
- método;
- construtor;
- `this`;
- encapsulamento;
- getters e setters;
- herança;
- polimorfismo;
- interfaces.

Essa fase é essencial. Spring usa POO o tempo todo.

## Fase 3 - Java intermediário

Objetivo: escrever código mais próximo do mundo real.

Estude:

- `List`;
- `ArrayList`;
- `Set`;
- `Map`;
- exceções;
- datas;
- arquivos;
- generics;
- lambdas;
- streams.

## Fase 4 - SQL

Objetivo: aprender banco de dados relacional.

Estude:

- banco de dados;
- tabelas;
- colunas;
- registros;
- chave primária;
- chave estrangeira;
- `SELECT`;
- `INSERT`;
- `UPDATE`;
- `DELETE`;
- `WHERE`;
- `ORDER BY`;
- `GROUP BY`;
- `JOIN`.

SQL conversa muito bem com Java backend.

## Fase 5 - Java com banco de dados

Objetivo: conectar Java com SQL.

Estude:

- JDBC;
- conexão com banco;
- CRUD;
- DAO;
- Repository;
- JPA;
- Hibernate.

## Fase 6 - Spring Boot

Objetivo: criar APIs reais.

Estude:

- Spring Boot;
- Controller;
- Service;
- Repository;
- injeção de dependência;
- API REST;
- validação;
- tratamento de erros;
- integração com banco de dados;
- projeto final.

## Projeto final sugerido

Crie uma API de alunos com:

- cadastro de aluno;
- listagem de alunos;
- busca por ID;
- atualização;
- exclusão;
- cálculo de média;
- situação aprovado/reprovado;
- persistência em banco de dados.

Esse projeto junta lógica, Java, POO, SQL e Spring Boot.
